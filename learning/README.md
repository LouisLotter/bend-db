# The learning process

Understanding comes before features. Each stage should let us predict what
happens, run the code, explain why, and state precisely what we have established.

- [Lesson 1: the in-memory store](lessons/01-memory-store.md)
- [Learning journal](JOURNAL.md): introduced concepts, verification, open questions
- [Design decisions](decisions.json): context, alternatives, choice, consequences
- [Learning website](site/README.md): runnable explanations and an interactive lab
- [Setup and toolchain](setup/README.md), with the original [playground](playground/)

The website is generated from these materials and the code in `../db`.
Edit the tracked lesson, journal, or decisions, then run `make site` at the
repository root. The website's notebook can hold reflections and decision
proposals; export those as Markdown and review them before adding to the journal.
Browser saves are local to that site's origin and browser profile.

No concepts are recorded as mastered yet. An explanation is an invitation to
understand, not evidence that understanding has happened.
